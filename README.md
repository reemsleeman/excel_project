# Excel Sales Analysis Project

## Overview
A practical Excel project focused on analyzing sales data and creating
meaningful reports using Microsoft Excel.

## Skills Demonstrated
- Data Cleaning
- Sorting & Filtering
- IF, SUM, AVERAGE, COUNT
- SUMIF, COUNTIF, AVERAGEIF
- VLOOKUP & XLOOKUP
- INDEX & MATCH
- PivotTables
- Charts
- Conditional Formatting
- Data Validation
- Duplicate Removal
- Text to Columns

## Project Features
- Sales data analysis
- Customer and product analysis
- PivotTable reports
- Interactive summaries
- Charts and visualizations

## Tools
- Microsoft Excel
